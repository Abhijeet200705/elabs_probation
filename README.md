# 📌 Task 1 – Excel Analysis

## 📌 Task Objective
Perform data analysis using Microsoft Excel and create:

- Pivot 1 – Summary by Category & Region  
- Pivot 2 – Monthly Sales Trend  
- 1 Chart for each Pivot Table  

---

## 📊 Excel Analysis

### 🔹 Pivot 1: Category & Region Summary
- Rows: Category  
- Columns: Region  
- Values: Sales / Profit (Summarized)  
- Chart: Column Chart  

**Purpose:**  
To analyze sales performance across different product categories and regions.

---

### 🔹 Pivot 2: Monthly Sales Trend
- Rows: Order Date (Grouped by Month)  
- Values: Sales  
- Chart: Line Chart  

**Purpose:**  
To identify sales trends and patterns over time.

---

## 🛠 Tools Used
- Microsoft Excel  
- Pivot Tables  
- Excel Charts

# 📊 Task 2 – Power BI Interactive Dashboard

## 📌 Task Objective
Develop a **fully interactive dashboard using Power BI** based on the same dataset used in Task 1.

---

## 📊 Dashboard Components

### 🔹 Sales by Category
- Visualization: Column Chart  
- Metric: Sum of Sales  
- Purpose: Compare sales performance across product categories.

---

### 🔹 Sales by Region
- Visualization: Pie Chart  
- Metric: Sum of Sales  
- Purpose: Show distribution of sales across different regions.

---

### 🔹 Monthly Sales Trend
- Visualization: Line Chart  
- Metric: Sum of Sales  
- Purpose: Analyze sales trends over time.

---

### 🔹 Top 10 Products by Sales
- Visualization: Bar Chart  
- Metric: Sum of Sales  
- Purpose: Identify the best-performing products.

---

### 🔹 Interactive Region Filter
- Visualization: Slicer  
- Purpose: Allows users to filter the dashboard by region for dynamic analysis.

---

## 🛠 Tools Used
- Microsoft Excel  
- Power BI  
- Data Visualization  
- Data Analysis
